# Database fields used by the event form

The event form and API now use only these existing `Events` columns:

- `EventID` (generated by SQL Server)
- `OrganiserID`
- `EventName`
- `EventDescription`
- `EventDate`
- `EventLocation`
- `EventStatus`
- `CreatedAt` (generated/defaulted by SQL Server)

Removed from the event form, MVC view model, API request, API projections, and EF Core mapping:

- `DistanceKm`
- `EventType`
- Event banner URL / banner upload field

No database migration or ALTER TABLE script is included. The supplied `RaceDay.sql` starter schema has also been aligned to the core event fields above for fresh test databases. **Do not run it against an existing database**; it is a CREATE TABLE script.

The remaining event status values are `open`, `closed`, `cancelled`, and `completed`, matching the existing `EventStatus` field and check constraint in the supplied schema.
